## 🏺 Overview / 概要
**Pharaoh’s Fortune** is an interactive web experience combining  
**Japanese classical poetry (Hyakunin Isshu)** with **ancient Egyptian-style fortune telling**.

プレイヤーは 8 首の和歌（A1〜B4）から1つを選び、  
詩の英訳と「Pharaoh’s Secret（ファラオの秘言）」としての運勢を受け取ります。  
東洋の詩的美と古代の神秘を、モダンなWeb体験でつなぐ試みです。

## 🎨 Features / 特徴
- Interactive poem selection system (A/B + number)  
  選択式の和歌システム（A/B + 数字）  
- English poetic commentary for each poem  
  各和歌に対応する英語版の詩的解釈  
- Animated “cover reveal” transition (49-piece effect)  
  49ピースによるアニメーション演出  
- Fortune message with cultural crossover themes  
  日本文化 × エジプト神話の融合による運勢メッセージ  
- Optional links to:  
  - End card (`end_card.html`)  
  - Next game (`gameC.html`)  
  - YouTube short version
